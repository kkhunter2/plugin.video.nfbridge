# Nflix

[English](README.md) | 한국어

Kodi에서 넷플릭스를 보는 애드온입니다. 작품은 Kodi 목록에서 고르고, 재생은 넷플릭스 창이
전체화면으로 떠서 합니다. 이 창은 윈도우에 들어 있는 Edge 엔진(WebView2)이라 넷플릭스가
정식 브라우저로 인정하고, 최대 4K로 재생됩니다. 자막은 Kodi에서 설정한 폰트와 색으로 나옵니다.

Windows 전용입니다.

## 준비물

- Windows 10 또는 11
- Kodi 20 이상. 홈페이지에서 받는 데스크톱판이어야 하고, Microsoft Store판 Kodi에서는
  동작하지 않습니다.
- 넷플릭스 계정. 4K로 보려면 넷플릭스가 정한 조건(프리미엄 요금제, 4K 화면 등)도 갖춰야 합니다.

Python 같은 다른 프로그램은 설치하지 않아도 됩니다. 필요한 것은 zip 안에 다 들어 있습니다.

## 설치

1. [Releases](https://github.com/kkhunter2/plugin.video.nfbridge/releases)에서
   `plugin.video.nfbridge-<버전>.zip`을 받습니다.
2. Kodi에서 애드온 → zip 파일에서 설치를 고르고, 받은 파일을 선택합니다.
3. 비디오 애드온에서 Nflix를 엽니다. 처음에는 "Netflix 로그인" 항목만 보입니다. 누르면
   넷플릭스 창이 뜨는데, 거기서 로그인하고 프로필을 고르면 창이 사라지고 Kodi로 돌아옵니다.
   로그인은 한 번만 하면 됩니다.

새 버전도 같은 방법으로 zip을 설치하면 됩니다. 로그인은 그대로 남아 있습니다.

윈도우 11의 스마트 앱 컨트롤이 켜져 있으면 플레이어가 막힐 수 있습니다.
[문제 해결](#문제-해결)을 보세요.

## 사용법

홈에는 넷플릭스 홈 화면의 줄들이 그대로 나오고, 맨 위에 검색, 내가 찜한 리스트, 시리즈와
영화, 프로필이 있습니다.

영화를 고르면 바로 재생되고, 시리즈를 고르면 시즌과 회차 목록이 나옵니다. 이어서 볼 위치와
다 본 표시도 Kodi 목록에 그대로 보입니다.

재생 중에는 키보드나 리모컨으로 이렇게 조작합니다.

| 키 | 동작 |
|---|---|
| 확인(Enter) | 화면에 "오프닝 건너뛰기"나 "다음 화" 같은 버튼이 있으면 누릅니다. 없으면 메뉴를 엽니다 |
| 방향키 | 메뉴가 열려 있을 때는 메뉴 이동, 아닐 때는 넷플릭스 기본 동작(앞뒤 이동, 음량) |
| 뒤로(Esc, Backspace) | 메뉴가 열려 있으면 닫고, 아니면 재생을 끝내고 Kodi로 돌아갑니다 |

메뉴에는 재생/일시정지, 자막, 다음 화(시리즈만), 뒤로가 있습니다.

자막 모양은 Kodi 자막 설정(폰트, 크기, 색, 테두리)을 따릅니다. 넷플릭스 기본 폰트를
쓰고 싶으면 Kodi의 자막 폰트를 기본값으로 두면 됩니다.

## 설정

| 설정 | 내용 |
|---|---|
| 재생 위치 | 기본값 "임베디드"는 애드온 창에서 재생합니다. "위임"을 고르면 넷플릭스 스토어 앱으로 넘기고, 앱이 없으면 Edge나 Chrome 창으로 엽니다. 위임에서는 Kodi 자막 모양과 위의 리모컨 조작이 적용되지 않습니다 |
| 프로필 전환 | 볼 프로필을 고릅니다. 홈의 "프로필"과 같습니다 |
| Kodi와 함께 Netflix 시작 | 기본으로 켜져 있습니다. Kodi가 켜지고 10초 뒤 넷플릭스를 뒤에서 미리 띄워 두기 때문에, 애드온을 열면 목록이 바로 나옵니다. 대신 Kodi가 켜져 있는 동안 메모리를 1GB쯤 씁니다. 넷플릭스를 자주 보지 않으면 꺼 두세요. 끄면 처음 열 때 10초쯤 걸립니다 |

이 밖에 Edge, Chrome 경로처럼 거의 손댈 일이 없는 설정이 몇 개 더 있습니다.

## 알아 두면 좋은 점

- 목록은 한 번 받으면 3시간 동안 저장해 두고 씁니다(내가 찜한 리스트는 1시간). 그래서 두
  번째부터는 바로 열리지만, 넷플릭스에 새로 생긴 줄은 조금 늦게 보일 수 있습니다. 작품을 보고
  나서 이어볼 위치와 다 본 표시는 바로 바뀝니다.
- Kodi로 다른 영상(내 파일, 다른 애드온)을 틀면 넷플릭스 창을 닫습니다. 둘이 소리 장치를 두고
  다투지 않게 하려는 것입니다. 다시 넷플릭스를 열면 알아서 다시 띄웁니다.
- 프로필을 바꾸면 저장해 둔 목록을 지우고 새로 받습니다.

## 문제 해결

**처음 열 때 오래 걸려요.**
"Kodi와 함께 Netflix 시작"이 꺼져 있으면, 처음 열 때 넷플릭스를 띄우느라 10초쯤 걸립니다.
켜 두면 Kodi가 켜질 때 미리 준비합니다.

**플레이어가 실행되지 않아요.**
윈도우 11의 스마트 앱 컨트롤은 서명되지 않은 프로그램을 막는데, 애드온에 들어 있는
플레이어가 서명되지 않은 프로그램입니다. 이럴 때는 서명된 Python으로 대신 실행하게 할 수
있습니다.

1. [python.org](https://www.python.org/)에서 Python을 설치합니다.
2. 명령 프롬프트에서 `py -m pip install pywebview fonttools brotli`를 실행합니다.
3. 애드온 설정 → 임베디드 플레이어 → "WebView2 호스트용 Python"에 설치한 `python.exe`를
   지정합니다.

스마트 앱 컨트롤을 꺼도 되지만, 윈도우 보안 기능이니 위 방법을 먼저 써 보세요.

**재생하면 D7361 오류가 나요.**
그래픽 드라이버나 윈도우를 업데이트한 뒤에 생기는 넷플릭스 DRM 오류입니다. Kodi를 다시
켜면 애드온이 이전 DRM 정보를 지우고 새로 받게 합니다.

**다른 넷플릭스 계정으로 바꾸고 싶어요.**
홈 맨 아래 "로그아웃"을 고르고 확인을 누르면, 로그아웃되고 Kodi 홈 화면으로 나갑니다. 애드온을
다시 열면 "Netflix 로그인" 항목이 나오니 다른 계정으로 로그인하면 됩니다. 0.3.2 이하 버전에서는 이 메뉴로 로그아웃되지 않으니, Kodi를 끄고
`%APPDATA%\Kodi\userdata\addon_data\plugin.video.nfbridge\webview_profile` 폴더를 지운 다음
다시 로그인하세요.

**넷플릭스에 새로 생긴 줄이 안 보여요.**
목록은 3시간마다 새로 받습니다. 바로 보고 싶으면 프로필 전환에서 지금 프로필을 다시 고르세요.
저장해 둔 목록이 지워지고 새로 받습니다.

## 왜 Windows 전용인가요

이 애드온은 화면 밖에 띄운 넷플릭스 창에서 목록을 읽고 같은 창으로 재생합니다. 이렇게
쓸 수 있으면서 넷플릭스가 인정하는 브라우저 엔진은 윈도우의 WebView2뿐입니다. macOS는 숨긴
창의 동작을 시스템이 늦춰 버리고, 리눅스에는 기본으로 쓸 만한 엔진이 없으며, 안드로이드와
LibreELEC에는 띄울 브라우저 자체가 없습니다. 2026년 10월에 검토했고, 지금은 다른 OS를 지원할
계획이 없습니다.

## 어떻게 동작하나요

애드온은 넷플릭스 웹사이트를 WebView2 창 하나에 띄워 둡니다. 이 창은 화면 밖에 있어서 보이지
않습니다. 목록이 필요하면 그 창에 들어 있는 넷플릭스 데이터를 읽어 Kodi 목록으로 보여 주고,
재생할 때는 같은 창을 앞으로 불러와 전체화면으로 엽니다.

DRM을 풀거나 우회하지 않습니다. 넷플릭스가 인정하는 브라우저 엔진이 평소처럼 재생할 뿐이고,
로그인도 각자 자기 계정으로 합니다. 같은 일을 Electron 같은 다른 내장 브라우저로 하면
넷플릭스가 재생을 거부합니다.

## 개발

직접 빌드하려면:

```
pip install pywebview fonttools brotli pyinstaller
python tools/package.py
```

`tools/package.py`는 플레이어가 소스보다 오래됐으면 PyInstaller로 다시 빌드하고, 저장소 바로
위 폴더에 `plugin.video.nfbridge-<버전>.zip`을 만듭니다. 플레이어는 파일 하나(onefile)가 아니라
폴더(onedir)로 빌드합니다. onefile은 실행할 때마다 압축을 푸느라 1초쯤 더 걸리기 때문입니다.

| 파일 | 하는 일 |
|---|---|
| `runtime/webview/webview_host.py` | 넷플릭스 창(데몬). 목록 데이터 읽기, 재생, 재생 중 메뉴 |
| `runtime/webview/fontfix.py` | Kodi 자막 폰트를 브라우저가 읽을 수 있게 고침 |
| `resources/lib/nfclient.py` | 데몬과 주고받기 |
| `resources/lib/routes.py` | Kodi 목록 만들기 |
| `resources/lib/player.py` | 데몬 실행, 재생, 위임 재생 |
| `resources/lib/cache.py` | 목록 저장 |
| `service.py` | Kodi 시작 시 미리 띄우기, 재생 뒤 소리 설정 되돌리기, Kodi 종료 시 데몬 끄기 |
| `resources/language/` | 12개 언어 문구 |

참고할 점:

- 데몬은 `127.0.0.1:8731`에서 HTTP 요청을 받습니다(`/health`, `/pinot`, `/falcor`, `/search`,
  `/episodes`, `/play` 등).
- 넷플릭스 목록 페이지는 2026년 10월부터 GraphQL("Pinot") 페이지입니다. 데몬은 페이지를
  스크롤해서 줄을 더 불러오고, 페이지의 Apollo 캐시에서 목록을 읽습니다. 작품별 정보(줄거리,
  이어볼 위치, 회차)는 falcor로 가져옵니다.
- 로그인과 DRM 정보는 `addon_data\plugin.video.nfbridge\webview_profile`에 있어서 애드온을
  업데이트해도 지워지지 않습니다.
- 번역은 `resources/language/*/strings.po`에 있습니다. 영어 말고는 초안이라, 어색한 곳을
  알려 주시면 고치겠습니다.
